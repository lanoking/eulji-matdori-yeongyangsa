# 🍚 을지로 맛도리 영양사

점심 메뉴 고르기 힘든 직장 동료들을 위한 **마블 룰렛 점심 추첨기**입니다.
만든 사람: 환경재단 jw

구슬 하나가 식당 하나이고, 코스를 내려와 결승선에 가장 먼저 닿는 구슬이 오늘의 메뉴가 됩니다.

- 대상 지역: 환경재단 인근 북창동 · 다동 · 무교동 · 명동/을지로
- 음식 종류: 한식 / 중식 / 일식 / 양식 / 다이어트식 / 전체
- 상황: 점심 / 저녁 / 회식(1인 3만원 이하 추정) / 전체
- 설치 없이 `index.html` 파일 하나로 동작합니다 (외부 라이브러리 없음, 폰트만 Google Fonts 사용).

## 사용 방법
1. 웹 페이지를 열고 음식 종류와 상황을 고릅니다.
2. **구슬 떨어뜨리기**를 누릅니다. (브라우저 정책상 버튼을 누른 뒤부터 소리가 납니다)
3. 결승선에 가장 먼저 닿은 식당 카드에서 네이버지도 / 카카오맵 링크로 바로 검색할 수 있습니다.

## 식당 목록 수정하기
`index.html` 안의 `RAW` 배열을 수정하면 됩니다. 한 줄이 식당 하나입니다.

```js
["이름", "종류", "상황", 평점, "지역"]
// 종류: 한 / 중 / 일 / 양 / 다(다이어트식)
// 상황: L=점심, D=저녁, G=회식(1인 3만원 이하)  예) "LDG"
// 지역: B=북창동, D=다동·무교동, M=명동·을지로
["무교동 북어국집", "한", "LD", 4.6, "D"],
```

## 데이터에 대해 (꼭 읽어주세요)
- 평점은 다이닝코드(2026-09-29 조회) 기준 **참고값**이며 3.5 이상만 담았습니다. 카카오맵·네이버 평점과 다를 수 있습니다.
- 점심/저녁/회식 분류와 "1인 3만원 이하"는 태그와 메뉴 종류로 정한 **추정**입니다. 실제 가격과 영업 여부는 방문 전에 확인해 주세요.
- 도보 1km 이내 여부는 거리를 계산하지 않았습니다. 명동 쪽 일부는 1km를 넘을 수 있습니다.
- 잘못된 정보나 추가하고 싶은 식당은 Issue 또는 Pull Request로 알려주세요.
